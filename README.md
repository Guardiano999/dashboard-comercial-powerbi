# 📊 Dashboard Comercial - Power BI

## 📌 Sobre o Projeto
Dashboard comercial desenvolvido no Power BI para análise de vendas e faturamento. O projeto apresenta KPIs estratégicos, faturamento por mês e estado, participação de vendedores e análise de produtos, utilizando DAX, modelagem de dados e visualizações interativas para apoio à tomada de decisão.

## 🚀 Indicadores Apresentados
- Faturamento Total
- Ticket Médio por Venda
- Preço Médio do Produto
- Maior e Menor Venda
- Faturamento por Mês
- Faturamento por Estado
- Participação por Vendedor
- Faturamento por Produto

## 🛠️ Ferramentas Utilizadas
- Power BI
- DAX
- Modelagem de Dados
- Visualização de Dados

## 🎯 Objetivo
Transformar dados comerciais em informações visuais para auxiliar análises estratégicas e tomada de decisão.
